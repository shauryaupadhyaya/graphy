Equations

This page contains information about plenty of math equations, both supported and not supported by the graphing calculator

Usage Guidelines

Certain features may not work completely. Please visit the GitHub repository and create an issue so we can fix it.
Graphing calculator is still being built, so not all features of a typical graphing calculator exist.

Supported Equations

1. Algebraic Equations & Functions

Graphy supports standard algebraic equations in the graphing calculator.
This is achieved through the Marching Squares algorithm, but at a very basic level.
Examples (of supported equations):

x2 + 4⁢y = 0 y = 10 ⁢ x + 15 y = x 2 + 3

2. Straight straight lines

Graphy supports very straight straight lines. hehe.
Examples:

x = 3 y = 10

3. Trignometric Identities

The following trignometric identities are supported:

sin(x) cos(x) tan(x) = sin(x) cos(x) csc(x) = 1 sin(x) sec(x) = 1 cos(x) cot(x) = 1 tan(x)

The support of these identies is established through the Math.JS library, delivered to the HTML file via a CDN.

4. Circle Equations

Circle equations are very interesting, and these equations CAN be plotted onto Graphy!

x2 + y2 = radius2

Above is the format for circle equations
Examples:

x 2 + ( y + 5 ) 2 = 5

1. Summation

Summation is a concept usually taught in higher grades of schools but this is a very basic example. It will likely be added once we finish with more common needs.
But basically is the addition of a sequence of numbers, functions, vectors, or other mathematical objects to find their total sum.

∑ i = 1 n x i

The Sigma Symbol (yes Sigma) - ∑; - tells you to add them all together.
The part i=1 tells us to start from the first element
The n tells us to stop at the last item, where n is the total count of items.
Finally, the xi represents the placeholder for each individual value in the list.

Here is an example of the answer from the Summation equation above, assuming n = 4

We have the following items in a list:

x 1 = 8 x 2 = 10 x 3 = 7 x 4 = 9

Expanding our summation ∑i=1nxi we get:

x 1 + x 2 + x 3 + x 4 = 8 + 10 + 7 + 9 = 34

2. Combinatorics

Combinatorics is a part of math focused on the study, counting, arrangement, and selection of elements within systems (number systems).

2.1 Factorial

Factorials are the simplest and easiest part of combinatorics. After factorial it only goes down haha.
A factorial is the product of all positive integers less than or equal to a given number n, written as n!

It is used for calculating how many ways distinct objects can be ordered or arranged.

Examples:

n ! = n × ( n − 1 ) × ( n − 2 ) × ( n − 3 ) × ...

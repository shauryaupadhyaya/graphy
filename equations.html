Equations

This page contains information about plenty of math equations, both supported and not supported by the graphing calculator

Usage Guidelines

Certain features may not work completely. Please visit the GitHub repository and create an issue so we can fix it.
Graphing calculator is still being built, so not all features of a typical graphing calculator exist.

Supported Equations

1. Algebraic Equations & Functions

Graphy supports standard algebraic equations in the graphing calculator.
This is achieved through the Marching Squares algorithm, but at a very basic level.
Examples (of supported equations):

x2 + 4⁢y = 0 y = 10 ⁢ x + 15 y = x 2 + 3

2. Straight straight lines

Graphy supports very straight straight lines. hehe.
Examples:

x = 3 y = 10

3. Trignometric Identities

The following trignometric identities are supported:

sin(x) cos(x) tan(x) = sin(x) cos(x) csc(x) = 1 sin(x) sec(x) = 1 cos(x) cot(x) = 1 tan(x)

The support of these identies is established through the Math.JS library, delivered to the HTML file via a CDN.

4. Circle Equations

Circle equations are very interesting, and these equations CAN be plotted onto Graphy!

x2 + y2 = radius2

Above is the format for circle equations
Examples:

x 2 + ( y + 5 ) 2 = 5

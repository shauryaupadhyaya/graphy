1. Summation

Summation is a concept usually taught in higher grades of schools but this is a very basic example. It will likely be added once we finish with more common needs.
But basically is the addition of a sequence of numbers, functions, vectors, or other mathematical objects to find their total sum.

∑ i = 1 n x i

The Sigma Symbol (yes Sigma) - ∑; - tells you to add them all together.
The part i=1 tells us to start from the first element
The n tells us to stop at the last item, where n is the total count of items.
Finally, the xi represents the placeholder for each individual value in the list.

Here is an example of the answer from the Summation equation above, assuming n = 4

We have the following items in a list:

x 1 = 8 x 2 = 10 x 3 = 7 x 4 = 9

Expanding our summation ∑i=1nxi we get:

x 1 + x 2 + x 3 + x 4 = 8 + 10 + 7 + 9 = 34

2. Combinatorics

Combinatorics is a part of math focused on the study, counting, arrangement, and selection of elements within systems (number systems).

2.1 Factorial

Factorials are the simplest and easiest part of combinatorics. After factorial it only goes down haha.
A factorial is the product of all positive integers less than or equal to a given number n, written as n!

It is used for calculating how many ways distinct objects can be ordered or arranged.

Examples:

n ! = n × ( n − 1 ) × ( n − 2 ) × ( n − 3 ) × ... × 3 × 2 × 1

Now there are some special cases like: both 0! and 1! = 1. And thats all for factorials! (for now)

2.2 Permutations

A permutation is an arrangement of items in a specific order. There are always rules to permutations.
If you have n distinct items, the number of ways to arrange them is n!

But this isn't the permutations you will be using the most in high school. It is partial permutations that is more common.
In partial permutations you pick k items out of n.

Heres the formula for Partial permutation: n!(n−k)!

Take a look at the example:

You are hosting a race with 5 runners (Alice, Bob, Charlie, David and Emma). You want to know how many different ways the Gold, Silver and Bronze medals can be awarded.

P k n = P 3 5 = 5! ( 5 − 3 ) ! = 5 × 4 × 3 × 2 × 1 2 × 1 = 120 2 = 60 ways

This calculation shows us that there are 60 ways to choose the first 3 places!!

2.3 Combinations

The man, the myth, the legend has arrived. We are FINALLY doing exactly what the name of this concept says - combinations!

A combination is a selection of items from a larger set where the order of selection does not matter.

If you pick items A, B,and C it is the same combination as picking C, A, B. This is what differentiates it from a permutation, where order does matter.

Here is the formula for Combination: C ( n , k ) = n ! k ! ( n − k ) !

Take a look at the example:

Imagine you have 5 fruits (Apple, Banana, Cherry, Date, Elderberry) and you want to choose 3 of them for a fruit salad.

Does order matter in a fruit salad? No. Apple-Banana-Cherry is the same salad as Cherry-Apple-Banana

Lets use the formula

C ( 5, 3 ) = 5 ! 3 ! ( 5 − 3 ) ! = 5 × 4 × 3 × 2 × 1 3 × 2 × 1 × 2 × 1 = 5 × 4 2 × 1 = 10 ways

With combination we found that there is only 10 UNIQUE ways to organise the given items into a salad! This number would have been much much higher if it was permutation, as ABC and CBA are different to permutation.

2.4 Binomial Theorem

The Binomial Theorem is a concept in algebra along with combinatrics that provides a formula to expand a formula to expand any binomial express raised to a non-negative integer power, into a sum of individual terms

( a + b ) 2 = ( n 0 ) a n b 0 + ( n 1 ) a n − 1 b 1 + ( n 2 ) a n − 2 b 2 + ... + ( n n ) a 0 b n

This is the formula for the binomial theorem, at least the expanded one. Here's the summation formula

( a + b ) = ∑ k = 0 n ( n k ) a n − k b k

Let's take a look at a example:

( x + 2 ) = ( 3 0 ) x 3 2 0 + ( 3 1 ) x 2 2 1 + ( 3 2 ) x 1 2 2 + ( 3 3 ) x 0 2 3

Collect the efficients (all the numbers on top of each other) and simplify, i.e.: ( 3 0 ) = 1 , ( 3 1 ) = 3 , ( 3 2 ) = 3 , ( 3 3 ) = 1 .

And now simplify the terms with the coefficients:

( x + 2 ) 3 = ( 1 ⋅ x 3 ⋅ 1 ) + ( 3 ⋅ x 2 ⋅ 2 ) + ( 3 ⋅ x ⋅ 4 ) + ( 1 ⋅ 1 ⋅ 8 )

Simplify that big expression!

( x + 2 ) 3 = x 3 + 6 x 2 + 12 x + 8

Tada! We got the expanded and simplified answer of this equation!

Now I know this is a rather easy expression and we actually don't need the binomial theorem, but for the sake of this example (and my fingers) we used a small value.

Binomial Theorem can be used to expand for example an expression to the power of 5 without breaking your brain!

And alas, you finally have a good understanding of the basics of Combinatorics!

3. Sequences and Series

Sequences and series are a concept of maths useful when theres repeating patterns or numbers and you are asked to find the relationship between them or to find the value of the Nth Term.

A sequence is a set of numbers or terms arranged in a specific logical order.

There are two types of series - finite and infinite

Take a look at the examples of sequences:

Finite:

2, 4, 6, 8, 10

Infinite:

2, 4, 6, 8, 10, ...

Notice there isn't a big difference in how they both are presented other than the ellipses(...) at the end of the infinite sequence.

Let us take a look at the different types of sequences

3.1 Arithmetic Sequences

Each term in an arithmetic sequence increases or decreases by a constant term.

This term is called the common differnence

Example:

3, 7, 11, 15, ...

Here you can see we add 4 to go from one term to the next each time.

The formula for getting the value of any term in an arithmetic sequence is:

a n = a 1 ( n − 1 ) d

Well you see all these letters, what do they mean?

an = the nth term you want to find

a1 = the value of the first term

n = the position of the term (e.g. n = 10 for the 10th term)

d = the common difference

Lets try using this in an example?

Find the 20th term of: 3, 7, 11, 15, ...

a 20 = 3 + ( 20 − 1 ) 4 = 3 + ( 19 × 4 ) = 79

Now the sum formulas, to find the sum of X number of terms

You can use these formulas to add up the first N terms of an arithmetic sequence quickly.

Option A: When you know the first and last terms

S n = n 2 ( a 1 + a n )

Or Option B: When you don't know the last term

S n = n 2 [ 2 a 1 + ( n &minus 1 ) d ]

Heres the breakdown of the stuff inside these 2 formulas:

Sn = the sum of the first n terms

an = the last term in the series

And now you know the Sum formulas and the Nth Term Formulas

Lets use the formula inside an example:

Find the sum of the first 10 terms of 3, 7, 11, 15

S 10 = 10 2 [ 2 ( 3 ) + ( 10 − 1 ) 4 ] = 5 [ 6 + 36 ] = 5 × 42 = 210

Now lets move on to geometric sequences

3.2 Geometric Sequences

In a geometric sequence each term is either multiplied or divided by a constant non-zero number

Example: 2, 6, 18, 54; where we are multiplying by 3 each time

The constant non-zero-number is often referred to as the common ratio

a n = a 1 ⋅ r n − 1

Wow more letters... what do they even mean?

an = the nth term you want to find

a1 = the very first term in the sequence

n = the position of the term

r = the common ratio (the number multiplied between terms)

Lets try out an example

a 6 = 2 ⋅ 3 ( 6 − 1 ) = 2 ⋅ 3 5 = 2 ⋅ 242 = 486

Ta-da! Its that simple!

Now for the sum formula for geometric

S n = a 1 ( 1 − r n ) 1 − r

There is just 1 condition for this formula. r ≠ 1 (r can never be 1, as that would just be the same number repeating again and again).

Lets try using the sum formula in an example:

Find the sum of the first 5 terms of 2, 6, 18, 54, ...

r = 6 2 = 3
S 5 = 2 ( 1 − 3 5 ) 1 − 3 = 2 ( 1 − 243 ) -2 = 2 ( 242 ) -2 = 242

And now you know how to find the sum of geometric sequence!

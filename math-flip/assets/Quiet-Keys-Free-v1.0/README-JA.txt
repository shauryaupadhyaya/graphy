QUIET KEYS — 無料キーボード入力ヒント v1.0
ailora will | 2026-10-26

チュートリアル・操作説明・ゲームHUD向けの、落ち着いた白とチャコールのキー素材です。
12種類：W/A/S/D、上/左/下/右矢印、E、Space、Enter、Esc。
各キーに通常 idle / 押下 pressed の2状態があります。

内容：SVG 24点（64×64 viewBox・図形とパスのみ）、透過RGBA PNG 72点（同じ24状態を32/64/256pxで収録）、プレビュー3点、英日README、利用規約、ファイル一覧、SHA256。
独自デザインは12種類です。96種類のデザインではありません。ゲームエンジン用プロジェクトは含みません。

使い方
1. 小さなUIにはpng/32、png/64、拡大用途にはpng/256を選びます。
2. 通常時にe-idle.png、入力を押している間にe-pressed.png、離したら通常へ戻します。この切り替え処理は利用者側で実装してください。
3. 両状態のキャンバス・表示サイズ・基準点を揃えます。押下状態ではキーの表面が画像高の5/64だけ下がる意図的な表現です。
4. 縦横比1:1を保持してください。小サイズは該当サイズのPNGを使うと鮮明です。各エンジンのフィルター・インポート設定は用途に応じて調整してください。
5. 画像の隣に「[E] 調べる」「[Space] ジャンプ」など、自分のゲームの操作名を添えてください。本素材はキー表示であり、操作を固定しません。キー変更・配列検出・アクセシビリティ用説明は実装側の責任です。
6. SVGはベクター編集ソフトでパスや色を変更できます。フォントの導入は不要です。

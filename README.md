# Graphy
Graphy is a small suite of tools related to math, it is a student made calculator website inspired by desmos. We currently include 3 tools +  a page full of topics that any student can use to learn them in some level of detail.

Tools we offer:
- Graphing Calculator
- Scientific Calculator
- 3D Calculator that can expand in the Z axis or stay 2D
- Math equations and concept explanation for our calculator usage
- A fun math game (flappy bird style)

# How to use - scientific?
Head over to the scientific calculator page and all usage information can be accessed by pressing the *i* button placed on the top of the calculator right beside the title "Graphy".

# How to use - graphing?
- Enter your equation in the sidebar and watch the magic as the equation gets plotted onto the graph.
- There is a pencil icon at the bottom, which allows you to change colour of the graph on it. 
- The X button at the top allows you to delete the graph on grid.
- To add more equations use the + button in the topbar
- To pan, simply click and drag anywhere in the graph
- To zoom in or out, use the pinch gesture on your touchpad

## Additional Information
- Functions like circle equation, and trig identities work for the graph. More complex functions like summation are to be added.
- Dark mode and light mode exists depending on your system preference. Theme colors are inspired by Catppuccin themes and colors. Light Mode uses Catppuccin Latte and dark mode uses Catppuccin Mocha.

# How to use - 3D?
Enter the equation in sidebar, and then to extend to Z axis, press the extend to Z button. Color editing and deleting works the same as graphing calculator. Dark and light mode works as well.

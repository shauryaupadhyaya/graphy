# Graphy
Graphy is a small suite of tools related to math. 
We currently include 3 tools +  a page full of topics that any student can use to learn them in some level of detail.
Tools we offer:
- Graphing Calculator
- Scientific Calculator
- 3D Calculator that can expand in the Z axis or stay 2D

# How to use - scientific?
Head over to the scientific calculator, and all usage information can be accessed by pressing the *i* button.

# How to use - graphing?
Enter your equation in the sidebar and watch the magic as the equation gets plotted onto the graph.
Panning will be added soon. 
There is a pencil icon at the bottom, which allows you to change colour of the graph on it. 
The X button at the top allows you to delete the graph on grid.
Functions like circle equation, and trig identities work for the graph. More complex functions like summation are to be added functionaliltiy.
Dark mode and light mode exists depending on your system preference.
Theme colors are inspired by Catppuccin themes and colors. Light Mode uses Catppuccin Latte and dark mode uses Catppuccin Mocha.

# How to use - 3D?
Enter the equation in sidebar, and then to extend to Z axis, press the extend to Z button.
Color editing and deleting works the same as graphing calculator.
Dark and light mode works as well.


# Equations Page info
The equations page can be accessed at /equations.
It includes information about the following topics:
1. Summation
2. Combinatrics
3. Sequences
4. Trignometry
5. Differentiation
6. Integration
7. Logarithms
8. Statistics

It can be used by students if they need a quick recap for the topics above.
Quickest way to find is to use the (upcoming) nav feature or use the browser's inbuilt find tool and type the name of the topic
